📤 build.py用エクスポート

scraper/build.py の COLUMNS = [ から ] までの部分をこのコードで置き換えてください。

デフォルトでは公開済みと予約公開（期日到来）のみ出力されます。下書きを含める場合は「下書きも含める」を使ってください。
設定するとコラムがSupabaseに直接保存されます

画像をアップロード

SupabaseのStorageに「column-images」バケット（公開）が必要です。
Supabase → Storage → New bucket → 「column-images」・Public にチェック
