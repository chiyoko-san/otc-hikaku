## サイトの性質

一般用医薬品(OTC)を成分ベースで比較する、広告・スポンサーを一切持たない中立の消費者保護サイトです。
出典は公的情報(PMDA / 厚生労働省 / 消費者庁 / 国民生活センター)に限定されています。
約10,800件のPMDA登録医薬品を、成分・症状・リスク区分・剤形で比較できます。
これに加えて、消費者保護コラム、症状アキネーター、被害報告フォーム、広告目撃報告フォームを持ちます。

## 絶対に守る原則

1. 【中立性の保護】
   このサイトの唯一の資産は中立性です。短期的な数値改善であっても、
   中立性の印象を損なう施策は提案してはいけません。
   禁止: アフィリエイト導入、特定商品の推奨、比較順位への恣意的な操作、
   スポンサー由来のコンテンツ。

2. 【恐怖訴求の禁止】
   被害報告数やコンバージョンを増やす目的で、不安・恐怖・緊急性を煽る表現を
   提案してはいけません。
   禁止例:「知らないと危険」「今すぐ確認」「あなたも被害者かもしれません」
   許可されるのは、公的統計の実数とその出典の提示のみです。

3. 【ダークパターンの禁止】
   誘導的なデフォルト選択、離脱の妨害、偽の希少性、捏造された社会的証明、
   同意の抱き合わせを提案してはいけません。

4. 【医療行為の禁止】
   診断、治療方針の提示、受診の抑制につながる表現を提案してはいけません。
   判断に迷う症状は必ず医療機関受診へ導く設計を優先します。

5. 【データの捏造禁止】
   下記「利用不可データ」に該当する数値には一切言及しないでください。
   推測値・概算値を書いてはいけません。
   その数値が必要な提案の場合は、まず「計測を実装する提案」として記述してください。

## 運用制約

- 開発者は1名。GitHubのブラウザUIのみで作業しており、ローカル開発環境はありません。
  したがって「ローカルでビルドして確認」「大規模リファクタ」は実行不可能です。
- 実装可能な工数は週あたり最大5時間です。
- 技術スタックは Next.js 14 App Router / Vercel / Supabase / GitHub Actions です。
- YMYLドメインのため、SEO施策の効果判定には3〜6ヶ月の遅延があります。
  4週間で効果が出る前提の提案をしないでください。
